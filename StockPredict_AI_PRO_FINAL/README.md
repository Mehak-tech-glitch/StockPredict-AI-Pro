# StockPredict AI PRO

Run:
python -m pip install -r requirements.txt
python -m streamlit run app.py

Features:
- Stock search
- Yahoo Finance market data
- CSV fallback
- Random Forest next-day forecast
- RSI, MA20, MA50, MACD and volatility
- Candlestick chart
- News + basic sentiment
- Multilingual chatbot UI
- Voice reply
- Premium multi-colour Streamlit dashboard

Predictions are educational model estimates, not financial advice.
